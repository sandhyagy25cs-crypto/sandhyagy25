Bug Squashers – AI Learning Equity Assistant
⭐ Project Overview

This project builds an AI Assistant that automatically analyzes student learning data and highlights:

hidden struggling groups
topics where learners fall behind
systemic imbalances
reasons for poor performance
personalized recommendations to make learning more equitable
⭐ Problem We Solve

Learning systems often look “uniform,” but different students face different struggles. Many gaps go unnoticed.

Our AI identifies these invisible gaps.

⭐ Key Features
🔍 Hidden disparity detection
🧠 AI explanations (why a group suffers)
🎯 Personalized learning recommendations
📊 Dashboard for teachers
📂 Easy CSV upload
⭐ Tech Stack
Python
pandas, scikit-learn
Streamlit
OpenAI API (optional for explanations)
GitHub for collaboration
⭐ How to Run

Install requirements:

pip install -r requirements.txt

Run the AI dashboard:

streamlit run dashboard/app.py

Upload a CSV → get insights.
